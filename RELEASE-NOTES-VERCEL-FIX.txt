UniTrade Vercel Reliability Update
==================================
- Switched Firebase compat script URLs to the stable 10.12.5 release used by this
  codebase's compat API.
- Added explicit Firebase initialization errors and script-load error reporting.
- Added diagnostics.js: visible Firebase setup warning, unhandled error reporting,
  and loader fallback so a failed initialization does not leave the page covered.
- Wrapped app/social initialization to log actionable failures instead of silently
  aborting all event bindings.
- Fixed Edit account to open the campus profile form rather than showing a placeholder.
- Fixed account signup error handling when Firebase Auth creates an account but a
  subsequent profile write fails; the user is told to sign in rather than register again.
- Added an explicit Firebase-auth guard before listing submission.
- Added vercel.json security headers and no-cache headers for active app assets.
- Added VERCEL-START-HERE.txt with deploy, Firebase, and troubleshooting steps.

Validation performed: JavaScript syntax checks, duplicate HTML-ID audit, local asset
reference audit, JSON validation, and ZIP integrity check. Live Firebase Auth, Firestore
rules, email delivery, real browser interactions on the deployed site, and the Vercel
domain cannot be verified from this workspace.
